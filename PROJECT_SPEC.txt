==================================================
1. 프로젝트 개요
==================================================

프로젝트명:
해밀학교 후원 프로젝트

프로젝트 목적:
해밀학교 학생들의 생활관비를 1:1 결연 방식으로 후원받을 수 있는 사이트를 구축한다.

이 프로젝트는 단순 소개 페이지가 아니라,
실제 운영 가능한 수준의 모금 시스템과 관리자 시스템을 포함해야 한다.

참고 사이트:
https://ubmk-70.vercel.app/

핵심 목표:
- 학생 60명의 생활관비 결연
- 학생 1명당 후원자 1명 연결
- 실제 운영 가능한 관리자 페이지 구축
- 후원 신청 및 입금 관리 시스템 구축
- 문자 발송 관리 기능 구축
- 갤러리 및 학생 관리 기능 구축

==================================================
2. 학교 정보
==================================================

학교명:
해밀학교

위치:
강원특별자치도 홍천군

설립:
가수 인순이(김인순) 설립

학생 수:
60명

학생 특징:
- 다문화 학생 비율 50% 이상
- 중도입국 학생 존재
- 경제적으로 어려운 학생 존재
- 기숙사 생활

후원 목적:
학생들의 생활관비 지원

생활관비:
월 약 10만 원

==================================================

로그인 방식:

- 단일 관리자 계정 사용

==================================================
5. 후원 정책
==================================================

후원 방식:
1. 일시후원
2. 정기후원

후원 금액:
- 일시후원: 10만 원 고정
- 정기후원: 월 10만 원 고정

정기후원 기간:
- 1개월
- 3개월
- 6개월
- 12개월
- 직접 입력 가능

결연 규칙:
- 학생 1명당 후원자 1명만 가능
- 입금 대기 상태가 되면 다른 사람 신청 불가
- 입금 완료 시 결연 완료 처리
- 취소 시 다시 신청 가능

입금 방식:
- 자동 결제 시스템 사용 안 함
- 신청 후 관리자가 직접 전화
- 수동 입금 확인 방식

결연 완료 기준:
입금 완료 상태 기준

12. 후원 신청 플로우
==================================================

1. 사용자가 학생 선택
2. 후원 신청 폼 작성
3. 신청 데이터 저장
4. 학생 상태를 입금대기로 변경
5. 관리자에게 문자 발송
6. 관리자가 직접 전화
7. 입금 확인
8. 관리자가 입금 완료 처리
9. 학생 상태를 결연 완료로 변경
10. 후원자에게 완료 문자 발송

==================================================
13. 문자 발송 플로우
==================================================

1. 후원 신청 발생
- 관리자에게 새 신청 문자 발송

2. 입금 완료 처리
- 후원자에게 완료 문자 발송

3. 정기후원 날짜 도달
- 후원자에게 안내 문자 발송

4. 매일 저녁
- 관리자에게 연락 필요 후원자 목록 발송
